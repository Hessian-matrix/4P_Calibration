04 / EXECUTION PROFILE

用本机算力，保留数值合同。

CPU 双精度求解为基线，可选择单线程兼容模式或 Rayon 多线程模式。

执行方案选择 · 设计草稿

hardwareConcurrency 只是浏览器报告的逻辑并发提示，不是可独占核心数。运行进度必须显示线程池实际启用的工作线程数。

兼容模式

单个计算 Worker，无需共享内存隔离，使用 CPU f64 求解。

Rayon 多线程模式

WASM 线程池需要跨源隔离和 SharedArrayBuffer；初始化完成后报告实际工作线程数。

    接口契约 · 尚未实现

    建议入口 window.fourP.request()。Agent 控制哪个浏览器，就使用那台机器的算力；文件必须显式授权。

    1. capabilities.get · 确认引擎与算力
    2. sources.bind / inspect · 绑定文件并扫描
    3. drafts.create / validate · 配置与预检
    4. runs.start / events · 启动和订阅进度
    5. runs.result / artifacts.read · 结果与产物

    GitHub Pages 不能提供远程 POST / MCP 服务。无浏览器 Agent 应使用额外的本地 MCP / CLI 服务。
