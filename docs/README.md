## 口径约定

- **设备配置优先**：地址、端口与启用能力以实际板端配置为准。
- **变换约定**只有一个写法：`T_target_source` 满足 `P_target = T_target_source · P_source`。
- **fail closed**：链路不通、尺寸不符、模型不可用一律报错并显示，从不静默回退
  （raw 取不到证据帧就**不拍**，绝不退回 RTSP 取图）。
